# LawnBot Maintenance Guide

## Simplified Diagnostic Procedure
1. Check perimeter cable connection
2. Clean charging base contacts
3. Inspect blade condition
4. Verify rain sensor functionality
5. Test manual operation mode
6. Check GPS signal (Max model only)

## Seasonal Maintenance
**Spring preparation:**
- Replace worn blades
- Calibrate perimeter wire
- Update firmware
- Clean sensors and chassis

**Winter storage:**
- Fully charge battery
- Store in dry location
- Remove blades for sharpening
