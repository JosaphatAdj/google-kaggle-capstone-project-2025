# XR Series Manual - Autonomous Vacuum Robots

## Models: XR25, XR30

### XR25 Technical Sheet
- **Autonomy**: 120 minutes
- **Battery**: Li-Ion 3400 mAh
- **Suction power**: 1800 Pa
- **Dustbin**: 450 ml

### XR30 Technical Sheet  
- **Autonomy**: 160 minutes
- **Battery**: Li-Ion 4400 mAh
- **Suction power**: 2400 Pa
- **Dustbin**: 520 ml

### Functional Architecture
**Subsystems:**
- Navigation Module (Lidar + IMU)
- Suction Module (brushless motor)
- Brushes Module (side + main brush)
- Charging Module (station + connector)
- Obstacle Detection Module
- Firmware & Diagnostics Module

**Replaceable components:**
- Battery
- HEPA filters
- Main brush
- Drive wheels
- Dust container
- IR sensors
