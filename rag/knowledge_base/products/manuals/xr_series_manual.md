# Manuel Série XR - Robots Aspirateurs Autonomes

## Modèles : XR25, XR30

### Fiche Technique XR25
- **Autonomie** : 120 minutes
- **Batterie** : Li-Ion 3400 mAh  
- **Puissance aspiration** : 1800 Pa
- **Réservoir** : 450 ml

### Fiche Technique XR30
- **Autonomie** : 160 minutes
- **Batterie** : Li-Ion 4400 mAh
- **Puissance aspiration** : 2400 Pa
- **Réservoir** : 520 ml

### Architecture Fonctionnelle
**Sous-systèmes :**
- Module Navigation (Lidar + IMU)
- Module Aspiration (moteur brushless)
- Module Brosses (latérales + centrale)
- Module Recharge (station + connecteur)
- Module Détection d'obstacles
- Module Firmware & Diagnostics

**Composants remplaçables :**
- Batterie
- Filtres HEPA
- Brosse principale
- Roues motrices
- Réservoir poussière
- Capteurs IR
