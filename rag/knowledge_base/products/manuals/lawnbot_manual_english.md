# LawnBot Series Manual - Autonomous Mowing Robots

## Models: LawnBot S, LawnBot Max

### LawnBot S Technical Specifications
- **Max area**: 600 m²
- **Autonomy**: 90 min
- **Sensors**: GPS-lite, rain sensor
- **Blades**: 3 rotary blades
- **Max slope**: 25°

### LawnBot Max Technical Specifications
- **Max area**: 1500 m²
- **Autonomy**: 130 min
- **High precision GPS**
- **Ultrasonic obstacle detection**
- **Max slope**: 35°

### Maintenance Schedule
- Change blades every 2 months
- Clean underside after each mowing
- Check perimeter cable each season
