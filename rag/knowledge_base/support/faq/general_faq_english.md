# General FAQ - Customer Support

## Common Problems & Solutions

### Robot won't start
**Probable causes:**
- Completely discharged battery
- Base station unplugged
- Dirty connectors

**Solution:**
- Check station (green LED)
- Clean robot contacts
- Charge for minimum 1 hour
- Long restart (10 seconds)

### Very weak suction
**Causes:** Clogged HEPA filter, blocked brush

**Solution:**
- Replace filter
- Clean main brush
- Check air intake

### Robot not returning to station
**Causes:** Obstacles, moved station, lost navigation

**Solution:**
- Check station line of sight
- Move away shiny objects (mirrors)
- Clean Lidar
