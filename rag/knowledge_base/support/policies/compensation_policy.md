# Politique de Compensation

## Actions Autorisées aux Agents
- Offrir un code promo (plafond : 10%)
- Offrir un accessoire (brosse, filtre)  
- Étendre support 1 mois

## Actions Requérant HITL
- Accorder un remboursement
- Proposer un remplacement complet
- Proposer une compensation financière
- Modifier la garantie
