# Règles de Communication Interne

## Structure Standard pour Annonces
1. **Contexte** (1-2 phrases)
2. **Détail du changement** 
3. **Impact sur les équipes**
4. **Date d'application**
5. **Contact de support**

## Newsletter Interne
**Contenus typiques :**
- Nouveaux produits et fonctionnalités
- Mises à jour agents IA
- Améliorations internes
- Annonces RH (arrivées, départs)
- Success stories clients

## Sécurité des Communications
- Jamais d'informations sensibles par message non sécurisé
- Uniquement via les canaux validés
- Accès limité selon rôle (privilège minimum)
- Authentification obligatoire
