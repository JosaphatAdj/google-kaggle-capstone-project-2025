# Internal Communication Rules

## Standard Announcement Structure
1. **Context** (1-2 sentences)
2. **Change details**
3. **Impact on teams**
4. **Implementation date**
5. **Support contact**

## Internal Newsletter
**Typical content:**
- New products and features
- AI agent updates
- Internal improvements
- HR announcements (arrivals, departures)
- Customer success stories

## Communication Security
- Never sensitive information via unsecured messaging
- Only through validated channels
- Limited access by role (minimum privilege)
- Mandatory authentication
