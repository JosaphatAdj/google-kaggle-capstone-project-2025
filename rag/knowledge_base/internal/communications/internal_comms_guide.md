# Guide de Communication Interne

## Types de Communications
- Annonces RH
- Changements organisationnels  
- Mises à jour système / IT
- Nouveaux employés
- Projets internes
- Newsletter interne

## Structure Recommandée pour une Annonce
1. **Contexte** (1-2 phrases)
2. **Détail du changement**
3. **Impact sur les équipes** 
4. **Date d'application**
5. **Contact ou ressource interne**

## Règles de Communication
- Ton professionnel et positif
- Pas de détails sensibles inutiles
- Toujours clarifier les prochaines étapes
- Encourager les questions
- Liens internes sécurisés uniquement

## Scénarios HITL pour Support Employés
**Cas RH sensibles :**
- Conflits internes
- Sanctions
- Promotions / augmentations
- Burnout / santé mentale
- Congés exceptionnels

**Cas IT sensibles :**
- Perte ou vol matériel
- Compromission de compte
- Accès administrateur critique
