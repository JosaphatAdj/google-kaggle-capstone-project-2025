# Onboarding Procedure

## Main Steps
1. **Internal account creation**
2. **Equipment assignment** (computer, badge)
3. **VPN + internal tools activation**
4. **Team introductions**
5. **Internal documentation access**
6. **Automated initial training**
7. **Final HR validation**

## Agent Automatable Tasks
- Send integration guide
- Create internal tool accounts (via API)
- Assign role-based access
- Schedule training sessions
- Personalized welcome message

## Tasks Requiring HITL
- Expensive equipment assignment (PC, smartphone)
- Physical introduction
- Document signing
- Personal question handling
