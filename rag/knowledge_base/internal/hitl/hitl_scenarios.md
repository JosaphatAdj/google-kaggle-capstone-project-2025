# Scénarios Human-in-the-Loop (HITL)

## HITL Obligatoire
- Remboursements & compensations élevées
- Problèmes matériels graves (batterie gonflée)
- Conflits internes RH
- Incidents IT critiques  
- Communications de crise
- Accès administrateur système
- Données RH sensibles
- Changements structurels permissions agents

## HITL Facultatif (selon niveau)
- Client mécontent mais coopératif
- Campagne marketing importante
- Changement planning équipe
- Demandes congés exceptionnels

## Limites des Agents
**Aucun agent ne peut :**
- Modifier structure interne du RAG
- Modifier permissions globales
- Accéder données RH complètes sans rôle approprié
- Déployer firmware
- Modifier logs système
- Effectuer transactions financières
