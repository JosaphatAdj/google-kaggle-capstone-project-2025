# Human-in-the-Loop (HITL) Scenarios

## Mandatory HITL
- Refunds & high compensations
- Serious hardware problems (swollen battery)
- Internal HR conflicts
- Critical IT incidents
- Crisis communications
- System administrator access
- Sensitive HR data
- Structural agent permission changes

## Optional HITL (depending on level)
- Dissatisfied but cooperative customer
- Important marketing campaign
- Team schedule changes
- Exceptional leave requests

## Agent Limitations
**No agent can:**
- Modify internal RAG structure
- Modify global permissions
- Access complete HR data without appropriate role
- Deploy firmware
- Modify system logs
- Perform financial transactions
