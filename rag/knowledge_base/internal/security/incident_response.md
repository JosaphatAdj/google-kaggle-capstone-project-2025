# Gestion des Incidents de Sécurité

## Types d'Incidents
- Accès non autorisé
- Compte compromis
- Fuite de données
- Perte/vol appareil interne
- Panne système critique
- Suspicion de malware

## Procédure Standard Incident
1. **Détection** : Automatique ou signalement employé
2. **Isolation** : Compte/outil isolé immédiatement
3. **Analyse** : Investigation rapide par IT interne
4. **Escalade** : Si impact global → gestion de crise
5. **Communication** : Interne si nécessaire
6. **Rapport** : Final + mesures préventives
