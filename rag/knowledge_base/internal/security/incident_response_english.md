# Security Incident Management

## Incident Types
- Unauthorized access
- Compromised account
- Data leak
- Internal device loss/theft
- Critical system failure
- Malware suspicion

## Standard Incident Procedure
1. **Detection**: Automatic or employee report
2. **Isolation**: Account/tool immediately isolated
3. **Analysis**: Quick investigation by internal IT
4. **Escalation**: If global impact → crisis management
5. **Communication**: Internal if necessary
6. **Report**: Final + preventive measures

## Administrator Access (CRITICAL)
**Always HITL mandatory for:**
- Modify global permissions
- Manage root certificates
- Deploy firmware
- Delete users
- Modify global authentication
- Access complete HR data
